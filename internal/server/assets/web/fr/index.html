02 / Protocoles

Un tunnel, trois protocoles

Le même parcours pour tous vos services locaux

Choisissez un protocole et un port local. Tunnel crée une route publique temporaire sans configuration supplémentaire ni changement dans votre façon de développer.

01 / WEBDisponible

HTTP

Sites web, API locales et WebSockets reçoivent automatiquement une adresse publique aléatoire.

$ … http localhost 3000
02 / STREAMDisponible

TCP

SSH, bases de données et autres services de développement basés sur TCP.

$ … tcp localhost 22
03 / DATAGRAMDisponible

UDP

Services UDP, intégration d’appareils et tests réseau temporaires.

$ … udp localhost 5353
