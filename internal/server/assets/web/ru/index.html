02 / Протоколы

Один туннель, три протокола

Один процесс для любого локального сервиса

Выберите протокол и локальный порт. Tunnel создаст временный публичный маршрут без дополнительной настройки и изменений привычного процесса разработки.

01 / WEBДоступно

HTTP

Сайты, локальные API и WebSocket автоматически получают случайный публичный адрес.

$ … http localhost 3000
02 / STREAMДоступно

TCP

SSH, базы данных и другие сервисы разработки на основе TCP.

$ … tcp localhost 22
03 / DATAGRAMДоступно

UDP

UDP-сервисы, интеграция устройств и временные сетевые тесты.

$ … udp localhost 5353
