02 / Protocolos

Um túnel, três protocolos

O mesmo fluxo para todo serviço local

Escolha um protocolo e uma porta local. O Tunnel cria uma rota pública temporária sem configuração extra nem mudanças no seu fluxo de desenvolvimento.

01 / WEBDisponível

HTTP

Sites, APIs locais e WebSockets recebem automaticamente um endereço público aleatório.

$ … http localhost 3000
02 / STREAMDisponível

TCP

SSH, bancos de dados e outros serviços de desenvolvimento baseados em TCP.

$ … tcp localhost 22
03 / DATAGRAMDisponível

UDP

Serviços UDP, integração de dispositivos e testes temporários de rede.
