02 / 프로토콜

하나의 터널, 세 가지 프로토콜

모든 로컬 서비스를 같은 방식으로 연결

프로토콜과 로컬 포트만 선택하면 됩니다. 추가 설정이나 개발 방식 변경 없이 임시 공개 경로를 만듭니다.

01 / WEB사용 가능

HTTP

웹사이트, 로컬 API, WebSocket에 임의의 공개 주소를 자동으로 제공합니다.

$ … http localhost 3000
02 / STREAM사용 가능

TCP

SSH, 데이터베이스 및 기타 TCP 기반 개발 서비스에 적합합니다.

$ … tcp localhost 22
03 / DATAGRAM사용 가능

UDP

UDP 서비스, 기기 연동 및 임시 네트워크 테스트에 적합합니다.

$ … udp localhost 5353
활용 사례API 연동실기기 테스트제품 데모단기 협업
