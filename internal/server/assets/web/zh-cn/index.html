02 / 协议

一条隧道，三种协议

同一套体验，连接不同服务

只需选择协议和本地端口，Tunnel 即可建立临时公网线路。没有额外配置，也不改变你的开发方式。

01 / WEB可用

HTTP

网页、本地 API 与 WebSocket，自动获得一个随机公开地址。

$ … tcp localhost 22
