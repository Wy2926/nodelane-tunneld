02 / プロトコル

1つのトンネル、3つのプロトコル

あらゆるローカルサービスを同じ手順で

プロトコルとローカルポートを選ぶだけ。追加設定や開発フローの変更なしで、一時的な公開経路を作成します。

01 / WEB利用可能

HTTP

Webサイト、ローカル API、WebSocket にランダムな公開アドレスを自動発行。

$ … http localhost 3000
02 / STREAM利用可能

TCP

SSH、データベース、その他の TCP ベースの開発サービス。

$ … tcp localhost 22
03 / DATAGRAM利用可能

UDP

UDP サービス、デバイス連携、一時的なネットワークテスト。

$ … udp localhost 5353
ユースケースAPI 連携実機テスト製品デモ短期コラボレーション
