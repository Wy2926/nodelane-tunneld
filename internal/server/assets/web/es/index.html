02 / Protocolos

Un túnel, tres protocolos

El mismo flujo para cada servicio local

Elige un protocolo y un puerto local. Tunnel crea una ruta pública temporal sin configuración adicional ni cambios en tu forma de desarrollar.

01 / WEBDisponible

HTTP

Sitios web, API locales y WebSockets reciben automáticamente una dirección pública aleatoria.

$ … http localhost 3000
02 / STREAMDisponible

TCP

SSH, bases de datos y otros servicios de desarrollo basados en TCP.

$ … tcp localhost 22
03 / DATAGRAMDisponible

UDP

Servicios UDP, integración de dispositivos y pruebas de red temporales.

$ … udp localhost 5353
