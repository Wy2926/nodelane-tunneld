02 / 通訊協定

一條隧道，三種通訊協定

同一套體驗，連接不同服務

只要選擇通訊協定與本機連接埠，Tunnel 就能建立暫時的公網線路，不需額外設定，也不會改變你的開發流程。

01 / WEB可用

HTTP

網站、本機 API 與 WebSocket，會自動取得隨機公開網址。

$ … http localhost 3000
02 / STREAM可用

TCP

SSH、資料庫與其他以 TCP 為基礎的開發服務。

$ … tcp localhost 22
03 / DATAGRAM可用

UDP

UDP 服務、裝置整合與暫時性網路測試。

$ … udp localhost 5353
適用情境API 串接實機測試產品展示短期協作
